# Segurança e privacidade

O repositório é público e contém somente documentação do projeto.

Não devem ser publicados:

- documentos internos;
- credenciais, chaves ou tokens;
- endereços privados;
- dados pessoais coletados de terceiros;
- respostas geradas a partir de fontes restritas;
- registros completos de execução contendo conteúdo sensível.

## Durante os testes

Use fontes neutras ou previamente autorizadas. Mantenha segredos fora do código e dos arquivos de configuração versionados. A coleta deve registrar apenas o necessário para investigar funcionamento, custo e falhas.

## Respostas do modelo

Uma resposta deve ser tratada como apoio, não como autorização para uma mudança em produção. A conferência da fonte e a revisão humana continuam necessárias.

## Relato de problema

Se encontrar uma informação sensível publicada por engano, não a reproduza em uma issue pública. Entre em contato pelo perfil do autor para que o conteúdo seja removido e as credenciais envolvidas sejam substituídas.

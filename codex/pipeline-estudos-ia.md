# Pipeline de estudos com IA

Use o repositório privado `soteropolitano/Codex` como referência dos arquivos e instruções do projeto.

1. Consulte as fontes em [originais/Estudos_IA](https://github.com/soteropolitano/Codex/tree/main/projetos/mvp-automacao-llm/originais/Estudos_IA).
2. O Gemini faz a triagem e prepara fontes limpas, preservando o conteúdo e sinalizando dúvidas.
3. O GPT consome as fontes selecionadas para criar planos de estudo, flashcards e simulados.
4. Salve novas fontes, resultados e configurações no diretório privado do projeto e confirme o commit.

A aplicação original foi aplicada no Google Cloud com o Google Drive. Esta instrução muda o local de consulta e salvamento dos arquivos de trabalho; não afirma que a aplicação em execução já lê ou grava no GitHub. Uma mudança no runtime exige alteração de código e validação.

Vídeos continuam fora do escopo. Quando uma fonte vier de vídeo, use uma transcrição revisada com o link e os marcadores de tempo.

A integração direta com o NotebookLM continua como possibilidade futura. Até lá, mantenha as fontes organizadas no repositório privado Codex.
